## What is working, incomplete, and next

**Working end to end:** everything in the checklist above. Permissions are enforced on the server: owner,
editor (edit), viewer (read-only), and no access (404).

**Intentionally not built / partial:**
- **Real-time collaboration:** concurrent edits are last-write-wins. Read-only viewers refresh every 5 seconds
  to see the owner's edits.
- **Authentication is mocked** (seeded accounts, no passwords). Authorization is real.
- `.docx` import drops images and tables (stated in the UI). Upload limit is 4 MB.
- No version history, comments, or export. No database migrations (schema is created by the seed script).

**With another 2–4 hours I would:** add Alembic migrations and CI; add version checks on save so concurrent edits
are detected instead of overwritten (then real-time editing with Yjs); add real auth and invites; add version
history and Markdown/PDF export. Details in `ARCHITECTURE.md`.
